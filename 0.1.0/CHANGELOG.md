# SoundCraft 0.1.0 BETA

- Added Page Up, Page Down and End key bindings for next, previous and pause/resume.
- Replaced the player Stop action with pause/resume, preserving the active sound source.
- Added a playback indicator and decorative disc that rotates once every five seconds during playback.
- Added configurable Minecraft-style now-playing notifications with a random vanilla disc icon.
- Bumped the mod version to 0.1.0.
